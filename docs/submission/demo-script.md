# 실제 화면 시연 대본

## 1차 제출: 120초 이내 MP4

실제 배포 화면을 1080p 이상에서 녹화합니다. 슬라이드나 이미지 나열로 동작 화면을 대신하지 않습니다. 아래는 녹화 순서이며 완성 영상이 아닙니다.

| 구간 | 실제 조작 | 짧은 설명 |
|---|---|---|
| 0~10초 | 홈에서 스타일 찾기 | 체형·상황·취향으로 실제 상품을 좁히는 서비스 |
| 10~30초 | 전신 또는 믹스 체형·성별 선택 | 이미 알고 있는 체형을 선택. 사진 진단 아님 |
| 30~45초 | '주말 카페와 산책', 추구미 '캐주얼', 태그 선택 | 같은 조건이 추천과 수정에 유지됨 |
| 45~70초 | 추천 실행 → 결과 화면 | 실제 API 응답을 기다리고 상품·가격·원본 이미지 확인 |
| 70~95초 | 상세에서 팬츠 변경 또는 예산 낮추기 | 요청한 부분의 변경과 나머지 상품 유지 확인 |
| 95~115초 | 로그인된 계정으로 상품 저장 → 내 옷장 | 현재 회원에게 저장되는 실제 동작 확인 |
| 115~120초 | 상품 링크·옷장 결과로 마무리 | 설명 근거·미확인 정보는 결과와 함께 확인 |

녹화 전 테스트용 Google 계정 로그인과 카탈로그 준비를 마칩니다. 로그인 자체를 보여주려면 시간을 따로 확보하고 계정 선택 화면의 개인정보가 노출되지 않도록 합니다. OAuth 비밀번호·토큰·관리자 키는 촬영하지 않습니다. 추천 지연으로 120초를 넘기면 다른 기능을 줄이거나 재촬영합니다. 성공 화면으로 바꿔치기하거나 실패를 성공으로 표시하지 않습니다.

### 녹화 전 점검

- `/health` 응답만으로 DB·AI 정상이라고 판단하지 않고 실제 추천을 한 번 실행한다.
- 코드에 `/api` 프록시가 제거된 배포본인지 확인한다. 요청 주소는 `api.gomin.today/recommendations`이다.
- 화면은 실제 상품을 표시해야 하며 홈 스타일 예시를 추천 결과처럼 설명하지 않는다.
- 회원 저장·삭제 후 다른 계정이나 로그아웃 상태에 정보가 남지 않는지 확인한다.
- 파일은 `해피엔딩팀_시연영상.mp4` 등 식별 가능한 이름으로 내보내고 재생 길이를 확인한다.

## 2차 발표: 7분

| 구간 | 내용 | 진행 제안 |
|---|---|---|
| 0:00~1:00 | 문제·사용자·서비스 개요 | 기획 담당 |
| 1:00~2:30 | AI 흐름·직접 개발·검증 | AI·백엔드 담당 |
| 2:30~5:45 | 실제 입력→추천→수정→회원 옷장, 3분 15초 라이브 | 프론트 담당 조작, QA 담당 상태 확인 |
| 5:45~7:00 | 외부 자원·한계·효과·확장 | 역할에 맞춰 분담 |

설명 3분 45초, 라이브 3분 15초입니다. 별도 Q&A는 5분입니다. 담당 배분은 발표 연습용 제안이며 첨부 발표본에 없는 발표자 지정이 확정됐다는 뜻은 아닙니다.
