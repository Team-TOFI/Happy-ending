# 해피엔딩팀 역할 분담

사용자가 제공한 발표 PDF 본문 7쪽을 기준으로 정리했습니다. 커밋 작성자 ID만으로 실명·역할을 추정하지 않았습니다.

| 팀원 | 담당 | 기여·산출물 |
|---|---|---|
| 김효원 | 기획·디자인·프론트엔드 | 서비스 기획, 브랜드 기준, 7개 핵심 화면, 조건 입력·코디 수정·옷장 UI |
| 김영규 | AI·백엔드 | 상품 수집·원문 속성 추출, AI 추천 API, 후보 구성·응답 검증, DB·인증 연동 |
| 김지민 | QA | 핵심 이용 흐름과 예외 상황 점검, 검수 피드백·재확인 |

주요 산출물 위치는 `frontend/`, `backend/app/`, `tools/scraping/`, `supabase/`입니다. 자동 테스트 수치나 모든 커밋을 특정 개인의 독립 기여로 환산하지 않습니다. 제출본의 실명·담당 범위는 팀이 최종 확인합니다.
