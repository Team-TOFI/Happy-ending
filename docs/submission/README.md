# 코디세이 AI 해커톤 2026 제출 안내

서비스 TOFI / 해피엔딩팀. 작성 기준은 제공된 참가자 가이드 3~6쪽과 「1. 해피엔딩팀 발표 자료 PPT.pdf」입니다. 첨부 발표 PDF는 수정하지 않았습니다.

## 제출물과 상태

| 제출물 | 가이드 요건 | 현재 확인·할 일 |
|---|---|---|
| 발표자료 | PDF, 표지 제외 10쪽 이하, 필수 7항목 | 첨부본은 표지 1+본문 10쪽, 7항목 있음. [점검 결과](presentation-review.md)의 출처 보완 필요 |
| 시연 영상 | 실제 화면 녹화 MP4, 2분 이하 | [120초 대본](demo-script.md) 제공. 이번 문서 작업에서 MP4는 생성하지 않음 |
| 소스 | 공개 GitHub 저장소 및 실행 방법 README | 루트·프론트·백엔드 README 갱신. 공개 상태 확인일 2026-11-01 |
| 소스 안내 파일 | `팀명_소스코드.txt`에 URL·최종 커밋 해시 | 문서 최종 커밋 후 생성한 파일을 사용. 추가 커밋하면 다시 생성 |

가이드상 제출은 팀별 Google Drive 업로드이며 마감은 **2026-11-01 13:00 KST**입니다. 마감 후 커밋은 심사에 반영되지 않습니다. 현재 문서 생성·커밋은 Drive 제출이나 심사 반영을 의미하지 않습니다. 제출 시각·접수 여부·주제 적합성은 팀이 운영 안내와 대조해야 합니다.

소스 안내 파일은 최종 커밋을 만든 뒤 `git rev-parse HEAD`로 해시를 확인해 작성합니다. 안내 파일 자체를 다시 커밋하면 최종 해시가 바뀌므로, 생성한 TXT는 저장소 밖의 제출 파일로 취급합니다. 이번 생성본은 worktree의 `output/submission/해피엔딩팀_소스코드.txt`에 둡니다.

## 업로드 전 확인

- [ ] 개회식 공개 주제의 실제 문구와 서비스 범위를 대조한다. 제공 파일에는 공개 주제 자체가 없어 여기서 적합 판정을 하지 않는다.
- [ ] 외부 자원 표에 `gomin-diary/gomin` CI 참고·변형 이력을 반영한다.
- [ ] 사전 보유 코드 해당 여부와 외부 참고 코드의 이용 권한을 팀이 확인한다. 발표본의 '해당 없음'을 저장소만으로 독립 확인하지 못했다.
- [ ] 실제 Google 로그인·추천·수정·회원 옷장을 배포 환경에서 점검한다.
- [ ] 영상은 화면이 읽히는 해상도로 녹화하고 MP4 재생 길이가 120초 이하인지 확인한다.
- [ ] 최종 PDF에서 표지 외 본문이 10쪽 이하인지 확인한다.
- [ ] 저장소를 비로그인 브라우저로 열고 README와 제출 커밋을 확인한다.
- [ ] `.env`·가상 키·DB 비밀번호·쿠키·Google Secret을 제출 파일에서 제외한다.
- [ ] 소스 안내 파일의 커밋이 실제 업로드하려는 최종 커밋과 일치하는지 확인한다.
- [ ] PDF·MP4·소스 안내 파일 세 종류를 팀 Drive에 업로드하고 완료 시각을 확인한다.
