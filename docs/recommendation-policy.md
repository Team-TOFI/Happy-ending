# 초기 추천 정책

버전: `2026-10-31.v1`. 실행 설정은 `backend/app/recommendation/policy.json`이다.
체형은 [사용자 제공 사진](references/body-style-reference.png)의 의복 지침을 사용했다. TPO·추구미는 초기 서비스 정책이며 사용자 평가에 따라 조정한다.

## 체형

| 유형 | 가점 특징 |
|---|---|
| Straight | 기본핏, V넥, 일자·H라인 |
| Wave | 슬림핏, 높은 허리선, 라운드넥, 허리 강조·프릴·리본 |
| Natural | 여유핏·오버핏, 와이드·세미와이드, 레이어드 |

전신 유형이 기본이다. 상체·하체 유형이 입력되면 해당 부위에 우선 적용한다. 체형은 스타일 선호 기준으로만 사용하며 사이즈 적합성을 보장하지 않는다.

## TPO

| 상황 | 우선 | 감점 |
|---|---|---|
| 일상 | 티셔츠·니트 등 일상복, 기본·여유핏 | — |
| 출근 | 셔츠·블라우스·니트·재킷·코트·로퍼 | 큰 그래픽 |
| 발표 | 셔츠·블라우스·니트·재킷·로퍼 | 그래픽·꽃무늬 |
| 면접 | 셔츠·재킷·코트·로퍼 | 후드·맨투맨·반소매 티·민소매 |
| 데이트 | 레이스·리본·프릴, 부드러운 질감 | — |
| 하객 | 블라우스·재킷·코트·로퍼 | 후드·맨투맨 |
| 여행 | 기본·여유핏, 바지·운동화 | — |

상황 규칙은 순위 조정이다. 사용자가 지정한 필수·제외 조건은 별도로 엄격하게 적용한다.

## 추구미

| 유형 | 가점 특징 |
|---|---|
| 미니멀 | 명시된 무지, 베이식·테일러드 |
| 클래식 | 셔츠·니트·재킷 등 기본 구성, 줄무늬·체크 |
| 페미닌 | 레이스·리본·프릴, A라인·머메이드 |
| 캐주얼 | 티셔츠·맨투맨·후드·운동화, 편한 핏 |
| 스트리트 | 오버핏·여유핏, 그래픽 |
| 보헤미안 | 명시된 보헤미안·빈티지, 표면 질감 |

## 점수와 설명

- 차원별 기본 50점에서 규칙 점수를 가감하고 0~100으로 제한한다. 체형 20%·TPO 40%·추구미 40%는 실험 가중치다.
- 사용자 선호는 가점을 주며 충돌하는 체형 규칙보다 우선한다. 명시적 제외는 후보에서 제거한다.
- 자동 추출은 `pending`. 후보와 점수에는 포함하지만 필수 속성 충족은 `approved`만 인정한다. `rejected`는 사용하지 않는다.
- 원문에 없는 값은 `null`. 장식 단어가 없다는 이유로 무지·미니멀을 생성하지 않는다.
- 코디마다 상품군별 최대 10개 후보를 조합한다. 재사용 상품은 탐색 단계에서 감점한다. 색상이 알려진 상품이 2개 이상이면 색상 수에 따라 ±2점 보정한다.
- 최대 3개 조합을 반환한다. 조합이 부족하면 개수를 줄이고, 미확보·조건 탈락 상품군은 생략 사유를 남긴다.
- 근거에는 규칙 ID·원문·검수 상태를 제공한다. 미검수 근거는 코디 요약에도 표시한다. 실측·공통 기준표는 추천 점수와 분리해 반환한다.
