# TOFI Next.js migration

Mode: Operate. 기존 v3 구성과 최신 토피넛·크림·에스프레소 배색을 유지하는 기술 스택 변환이다. 새 시각 방향을 만드는 작업은 포함하지 않는다.

7개 화면을 App Router 경로로 분리한다. 서버 페이지는 메타데이터와 동적 경로 매개변수를 다루고, 실제 선택 컨트롤은 React 클라이언트 컴포넌트로 구현한다. 프로필·옷장·추천 당시 조건은 타입이 있는 외부 저장소에 보관하며, 서버 초기 스냅샷에는 개인 정보를 넣지 않는다.

사용자는 체형 → TPO → 추구미 → 추천 비교 → 아이템·수정 → 옷장으로 이동한다. 뒤로 이동해도 입력을 유지하고, 새로고침 후 같은 브라우저의 저장 정보를 복원한다. 실제 API 연동은 사용자 요청에 따라 후속 작업으로 남긴다.

시각 기준: 크림 바탕과 작은 상품 이미지, 밝은 토피넛 선택 상태, 에스프레소 글자·주요 버튼, 숫자 헤더와 상품 2×2, 모바일 세로 재배치. 기존 검수본의 CSS와 이미지 자산을 이어받았다.
