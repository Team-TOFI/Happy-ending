# TOFI product

토피는 본인의 바디타입을 알고 있고 취향에 관심이 있지만 쇼핑에 쓸 시간이 부족한 사람을 위한 스타일 셀렉션 서비스다. 체형·TPO·추구미로 후보를 최대 세 코디로 좁히고, 사용자는 필요한 부분을 수정하거나 관심 상품을 옷장에 저장한다.

## Platform and stack

Web. 저장소의 기존 Next.js 16.4.3 · React 19.3.0 · TypeScript App Router 구성을 유지한다. 페이지와 메타데이터는 서버 컴포넌트, 선택과 저장은 클라이언트 컴포넌트로 구성한다.

## Product commitments

- 이름: tofi / 토피. 메인 카피: 취향은 선명하게, 쇼핑은 단순하게.
- 설명: 바디타입과 추구미를 바탕으로 T.P.O에 맞는 스타일을 제안합니다.
- 가장 최근에 지정한 색상: 토피넛 라이트 브라운·크림·에스프레소. 기존 진한 모카무스보다 우선한다.
- 단일 타입과 상체·하체 믹스를 직접 선택한다. 체형 진단이나 사진 분석은 제공하지 않는다.
- TPO: 출근·등교·면접·발표·데이트·모임·경조사·여행·외출·파티.
- 추구미 이미지 카드 한 가지와 태그 최대 세 개.
- 결과 제목 Tofi Pick, 카드 헤더 01/02/03, 해시태그 이름, 상품 2×2, 상세 버튼 아이템 확인하기.
- 코디 수정 시 추천 당시 조건을 유지한다. 내 옷장은 관심 상품 보관 공간이며 실제 소유 의류를 뜻하지 않는다.
- 입력과 옷장은 같은 브라우저에 저장하며 계정·기기 간 동기화는 후속 범위다.

## Current scope

7개 화면, 샘플 추천·수정, 대기·오류·빈 결과·재시도, 저장·취소·분류·메모·복원, 모바일·키보드 선택을 제공한다. 실제 추천 서버 연결은 사용자가 후속 작업으로 분리했다. 상품·가격·이미지·코멘트는 시연용이며 실제 추천 품질이나 구매 정확도를 주장하지 않는다.

서비스 기획서는 저장소 루트의 `TOFI_서비스기획서_v3.0.md`, 최신 디자인 기준은 이 폴더의 `DESIGN.md`다. 본 문서의 밝은 팔레트와 UI 문구가 이전 모카무스 표기보다 우선한다.
